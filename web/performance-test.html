🔥 Performance Diagnostic Tool

📋 INSTRUCTIONS:
1. Open Chrome Task Manager: Shift+Esc or Menu → More Tools → Task Manager
2. Find the "Tab: Performance Diagnostic" row
3. Note the CPU % before each test
4. Run each test for 10 seconds
5. Note the CPU % during each test
6. The test causing the biggest CPU increase is the culprit!

📊 Live Performance Monitor

📈 INTERPRETING RESULTS:
• Baseline: Should be 0-2% CPU
• Animations: If this jumps 10%+, CSS effects are the issue
• Music: If this jumps 15-30%, audio decoding is the issue (most common!)
• Rendering: If this jumps 10%+, DOM updates need optimization
• Combined: This is what your game uses during play

💡 TIP: Close other tabs and stop other programs for accurate results!
